Compass 3.0.0

AI báo “xong” khi chưa xong

Nó không nói dối. Nó thật sự tin là đã xong — vì không có gì bắt nó chứng minh.

Compass là lớp bắt chứng minh đó. Bạn vẫn giao việc như bình thường; Claude tự chạy gate, và chỉ exit code mới được phán pass hay fail. Dưới đây là một task thật, chạy từ đầu đến cuối.

Một task, từ lời nhờ đến bằng chứng

Output trong các khối đen là những gì Compass thật sự in ra khi chạy task này trên examples/todo. Không có dòng nào viết lại cho đẹp.

Bạn

Thêm nút “Xóa việc đã xong” vào danh sách todo.

Claude

Đọc src/App.jsx trước, rồi phân loại: một module, có giao diện — feature-s, tối thiểu 13 test case.

$ compass init TD-002 --type=feature-s Đã tạo task TD-002 (loại feature-s) spec: .compass/TD-002/spec.md → Điền spec, rồi chạy: compass spec TD-002
Claude viết spec

Mục tiêu, ràng buộc, và phần khó nhất — rủi ro hồi quy: nút đặt trong form thì bấm xóa sẽ gửi luôn chữ đang gõ dở; xóa theo tiêu đề thay vì theo id sẽ xóa nhầm khi hai việc trùng tên. Rồi 13 test case, mỗi case một kỳ vọng đo được.

$ compass spec TD-002 ✓ Gate spec PASSED → Đưa spec cho người duyệt. Duyệt xong mới bắt đầu code.
Bạn duyệt

Ổn, làm đi.

Claude viết code và test

Test trước, thấy đỏ, rồi mới implement. Xong, chạy gate.

$ compass check TD-002 ✓ Gate spec PASSED ✓ Gate knowledge PASSED — 6 file nguồn còn khớp tài liệu ✓ Gate secrets PASSED — không thấy file .env nào trong diff ✓ Gate convention PASSED — 4 luật, 4 file, không vi phạm ✗ Gate test FAILED Spec khai báo 13 test cases, chỉ tìm thấy 12 đã chạy. Không tìm thấy dấu vết: EC3 → Viết test cho các case còn thiếu, hoặc sửa spec nếu chúng không còn cần thiết (sửa spec cần duyệt lại).

Đây là chỗ Compass đáng tiền

Suite xanh. Mọi test viết ra đều pass. Không có gì trên màn hình nói rằng việc chưa xong — trừ Compass, vì nó đối chiếu từng ID trong spec với output thật và thấy EC3 chưa từng chạy.

Không có gate này, Claude báo “xong, 12 test pass”, và bạn tin. Case EC3 — đánh dấu rồi bỏ đánh dấu, bấm nút, việc đó vẫn phải còn — không ai viết, cho tới lúc nó vỡ trên production.

Claude viết nốt test còn thiếu

Gate chỉ đúng ID thiếu, nên không phải đoán. Thêm test EC3, chạy lại.

$ compass check TD-002 ✓ Gate spec PASSED ✓ Gate knowledge PASSED — 7 file nguồn còn khớp tài liệu ✓ Gate secrets PASSED — không thấy file .env nào trong diff ✓ Gate convention PASSED — 4 luật, 5 file, không vi phạm ✓ Gate test PASSED — 13/13 test cases đã chạy ✓ Gate ui PASSED — 16 thuộc tính, 2 viewport, không lệch ✓ Gate visual PASSED — đã tạo baseline cho 2 viewport Baseline: .compass/TD-002/baseline/ → Lần này chưa so gì cả — xem ảnh, thấy đúng thì commit baseline vào git.
Claude đóng task
$ compass done TD-002 ✓ Gate done PASSED — 7 gate đã pass Task TD-002 hoàn thành. Bằng chứng: .compass/TD-002/evidence/

Giờ “xong” mới là xong — và có thư mục bằng chứng để đối chiếu.

Lần chạy này quay trước khi gate review áp cho task cỡ feature-s. Giờ task cỡ này còn qua thêm một bước: một phiên AI khác soi theo mười tiêu chí, rồi done mới đóng được.

Ai làm gì

Ranh giới này là toàn bộ ý tưởng. AI giỏi viết; nó dở ở chỗ tự chấm bài mình.

ViệcAICompass
Viết spec, code, test✓—
Chạy test, đo, kiểm tra—✓
Ghi bằng chứng—✓
Phán pass / fail—✓

Bản ghi gate có chữ ký. Sửa tay là lộ — sửa giá trị, chuyển khe, hay chép từ task khác đều bị bắt.

Tám gate

Chạy theo thứ tự rẻ trước đắt sau, dừng ngay khi có cái đỏ.

GateĐo gì
specSpec đủ mục, test case có ID và kỳ vọng đo được
knowledgeTài liệu máy sinh còn khớp code
secretsFile .env không lọt vào commit
conventionQuy ước dự án, viết một lần chạy mãi
testSuite xanh và mọi test ID trong spec đã thực sự chạy
uiSố đo CSS thật khớp design contract (±2px)
visualSo pixel với baseline đã duyệt
reviewAgent khác soi theo 10 tiêu chí, phải kết luận cho từng tiêu chí
